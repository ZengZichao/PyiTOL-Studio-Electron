# 设计系统

[English](../en/design-system.md) | [简体中文](../zh/design-system.md)

PyiTOL Studio 的视觉语法：颜色、字体、间距、层级与组件约定。前端实现与该体系的偏差由设计审查报告（[英](frontend-design-review.md) / [中](frontend-design-review.md)）逐项核查。

## 设计权威

本体系派生自 Apple DESIGN.md，并为本产品约定了四处显式覆盖：

1. **品牌色** —— 国际克莱因蓝（IKB）取代系统蓝，作为唯一强调色。
2. **单色树形标志** —— 应用图标/树形标志为单色，不用渐变。
3. **双主题** —— 浅色与深色是一等公民，不是互相反色。
4. **桌面密度** —— 控件度量面向鼠标/键盘使用，而非触屏。

## 颜色

| 令牌     | 浅色                                          | 深色      | 用途                     |
| -------- | --------------------------------------------- | --------- | ------------------------ |
| 强调色   | `#002FA7`（IKB）                              | `#2e5cff` | 主操作、选中、焦点、链接 |
| 主文字   | 近黑                                          | 近白      | 正文                     |
| 次级文字 | —                                             | —         | 说明、元数据             |
| 表面     | 白 / 浅灰阶梯                                 | 深灰阶梯  | 窗口、卡片、面板         |
| 语义色   | success / warning / danger（见审查报告 §5.3） |           | 仅用于状态               |

规则：

- **只有一种强调色。** 没有第二种品牌色，没有渐变，界面框架不着色。
- 语义色保留给状态；绝不借用强调色表达错误或成功。
- 所有颜色必须来自主题令牌（Tailwind v4 `@theme` 变量）—— 组件里的硬编码色值是审查问题（TKN-03）。

## 字体

- 系统字体栈（macOS 上为 `-apple-system`、SF Pro）—— 不打包网页字体。
- 字号来自令牌阶梯（`--text-*`）；避免随手的 px 值。
- 表格数字用等宽数字（tabular numerals）；模板文本与 Newick 内容用等宽字体栈。

## 间距与形状

- 间距使用 Tailwind v4 令牌命名空间（`--spacing-*`）。审查报告（LAY-01）记录了该命名空间的工具类生成当前失效 —— 数值必须由令牌生成，而非魔数。
- 圆角：小控件用小圆角令牌；卡片与对话框用大圆角。同一组件内不得混用圆角。
- 界面框架上用边框而不是阴影做分隔；阴影保留给浮层（右键菜单、命令面板、Toast —— `--shadow-2` / `--shadow-3`）。

## 主题

- 三种模式：`light`、`dark`、`system`（跟随 `nativeTheme`，变化经 `platform:theme-changed` 推送到渲染层）。
- 必须设置 `color-scheme`，让原生控件（输入框、滚动条、对话框）与当前主题一致（审查报告 §5.5）。
- 对比度：文字配对应满足 WCAG 2.x AA（普通文字 4.5:1，大字 3:1）；各令牌配对的实测值见审查报告 §5.4。

## 组件

- **按钮** —— 一种主样式（强调色填充）、一种次样式（安静）、图标按钮；每种样式都要有 hover/active/focus-visible 状态（审查报告 §7.1）。
- **对话框** —— `role="dialog"`、`aria-modal`、焦点圈禁、Esc 取消、关闭后归还焦点（审查报告 §7.3）。
- **数据表** —— 核心界面：行高与内边距按桌面密度，数字列右对齐，表头吸附（审查报告 §7.2）。
- **命令面板（⌘K）** —— 模糊过滤、键盘优先、Esc 关闭。
- **Toast / 状态** —— 瞬时反馈出现在状态栏或 Toast；错误可关闭、可复制。
- **状态** —— 每个异步界面都要定义 空态 / 载入 / 错误 / 成功（审查报告 §7.9 矩阵）。

## 可访问性基线

- 语义 HTML 优先；语义不足才用 ARIA（审查报告 §9.1：当前渲染层 ARIA 覆盖为 0）。
- 全键盘可达；焦点环用强调色且可见。
- 不单独用颜色传达状态。
